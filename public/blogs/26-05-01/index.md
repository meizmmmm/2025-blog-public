# 🧠 DeepSeek API + Cherry Studio 使用总结（速查版）

------

# 🧩 一、核心概念（一定要记住）

## ✅ API 是什么？

👉 **用代码调用AI的入口**

类比：

- 你 = 用户
- API = 服务员
- 模型 = 厨房

👉 本质：
**发请求 → AI处理 → 返回结果**

------

## ✅ 你现在的状态

👉 你已经在用：

👉 **Cherry Studio + DeepSeek API**

👉 等于：
**不用写代码，也在调用模型**

------

# ⚙️ 二、Cherry Studio 核心设置（重点）

------

## 🔥 1. 推理模式（你同学帮你开的）

### 当前设置：

```json
reasoning_effort: max
thinking: enabled
```

👉 含义：

- 🧠 thinking：开启“先思考再回答”
- 🔥 max：最强推理（最耗资源）

------

## ⚠️ 影响（非常关键）

👉 在这个模式下：

❗ **temperature 基本不起作用**

------

## 🎛️ 2. temperature（温度）

## 📍 位置：
👉 模型设置里的滑条

📊 作用：

| 值   | 效果             |
| ---- | ---------------- |
| 0.2  | 很稳（适合代码） |
| 0.7  | 平衡（推荐）     |
| 1.2+ | 发散（写作）     |

------

# 🧠 三、推荐配置（直接照用）

------

## 🟢 日常模式（最常用）

```text
reasoning_effort: high 或关闭
thinking: 可开可关
temperature: 0.6~0.8
```

👉 用于：

- 写作业
- 问问题
- 日常使用

------

## 🔴 高推理模式（你现在这个）

```text
reasoning_effort: max
thinking: enabled
```

👉 用于：

- 数学难题
- 编程分析
- 复杂逻辑

# 🧩 四、Cherry Studio 高效用法（比设置更重要）

------

## 1️⃣ 固定人设（强烈推荐）

